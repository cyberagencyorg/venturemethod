# Completely fictional reference case

This directory is a worked *format example*, not verified external research and not a real client. Source and company names are fabricated to demonstrate what must remain distinguishable.

## Situation

An invented operations software vendor, ExampleCo, hypothetically considers an expansion into regional logistics operations. The venture architect's job is to decide whether initial customer research is worth funding, not to write a speculative product roadmap as if demand has been established.

## First useful work

- Define the decision: "Which customer jobs should be tested before committing to a build?"
- Research original market size sources with dated geographic definitions, or declare unavailable.
- Write interview guide around past behavior and existing workarounds.
- Create provisional buyer and alternatives hypotheses.
- Establish a low-cost test and discontinuation rule.
- Do not claim that interviews, customer demand or financial viability have already been verified.

## Reference output

- Engagement charter, unverified assumption register, research requests.
- Recommended skills: intake-scoping, market-landscape, opportunity-discovery, venture-thesis, experiment-design, adversarial-review.
- Result: defer build recommendation pending customer evidence. This is an illustration of decision hygiene, not an actual investment conclusion.
