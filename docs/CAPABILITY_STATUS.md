Checked against local v0.6 source and tests. **Implemented** means a local code path exists and passes structural tests. It does not mean the associated professional method has been independently validated.

## Release acceptance principles

A larger catalog is not a quality achievement. Before a new capability is treated as production-ready it should have a bounded purpose, real source and licensing review, explicit inputs/outputs, an adversarial test, at least one realistic end-to-end example, a failure-mode description, and independent assessment of substantive quality.

We should also measure useful work completed per unit of human attention, not just agent speed, output volume or test count.
