# v0.2 local release notes

## Implemented since v0.1

- Single-writer hash-chained local event journal, immutable record creations, projection validation and manual recovery function.
- Typed local record chains: entity candidates, sources, claims, hypotheses, options, decisions, actions, outcomes, reviewer assertions and artifacts.
- Missing and cross-engagement record references rejected at creation; quality checks detect inconsistent projections and broken references.
- Intake contract updates recorded through the CLI; scope, audience, permissions and risk fields remain human-supplied.
- Explainable deterministic functional router that uses engagement kind and explicit objective, not a generic fixed product sequence.
- Eight new original cross-functional skills: GTM, capital, financial scenarios, brand, systems diagnosis, commercial offers, service blueprint, institutional landscape. 25 original skills in total.
- Passive registry of external skill candidates with pinned Git refs, claimed license and review state; never downloads or runs outside code.
- Private content-addressed local Markdown decision briefs and context packs with provenance and independent-review caveats.
- Paired skill evaluation workspace initialization and strictly incomplete results without real case runs plus human grading.
- Updated structural and adversarial tests, detailed system design and gap analysis.

## Known limitations

- No model/agent runner, online research integration, native slide/spreadsheet/doc generator, GitHub repo creation, database, identity verification, external publication, real customer outcomes or verified independent agent benchmark.
- Local hashes detect inconsistency against recorded journal; they are not cryptographic proof of authorship.
- No automatic license compliance guarantee. License claims need to be checked against exact upstream commit and assets.
- Reviewers typed into local CLI are assertions, not authenticated signers.
- The router is heuristic and may route poorly; domain evaluation is mandatory before relying on it.

## Next release (v0.3)

1. Strong versioned ontological schemas and persistent independent evidence provenance, contradiction edges, entity identity matching.
2. Research adapter and official-source collector with snapshots, access rights, dates, canonical URL/author and refresh/difference records.
3. One runnable harness adapter for isolated, budgeted with-skill and no-skill evaluation, meaningful adversarial tests, blind review, structured report and rollback.
4. Two end-to-end output families, such as a verified company dossier and venture opportunity decision memo, evaluated against real cases.
5. Explicit rights-controlled scoped handoff adapter to Open ASS or Creative Studio, with dry run as default.
