# Copy Editing

**Purpose:** Diagnose and repair the draft by independent editorial dimensions. Respect its existing structure unless a specific structural fault justifies changing it.

## When to use
Use when an existing draft needs editorial improvement without an automatic wholesale rewrite. Work only within the requested scope.

## Inputs
Existing draft, accepted version, canonical marketing context, buyer and channel, original claim evidence, owner constraints and requested edit scope.

## Before editing
Load project marketing context, original draft and owner restrictions. Mark the requested edit scope. If the underlying position is unproved or internally contradictory, flag for `competitive-positioning` rather than disguising the failure with smoother sentences.

## Method
1. **Argument:** Is each paragraph necessary? Does it make a buyer-relevant point?
2. **Factual accuracy:** Verify or constrain achievements, evidence, claims and provenance. Attribute founder experience properly.
3. **Specificity:** Replace abstractions with known mechanisms, precise work or evidence. Never invent an example.
4. **Reader:** Does the intended buyer understand applicability, scope and reasons to believe?
5. **Voice:** Preserve accepted terms, point of view and confidence. See `brand-voice-preservation` if this is a substantive risk.
6. **Structure:** Eliminate duplicated conclusions, empty transitions, unsupported contrasts, repetitive catalogs and surplus sections.
7. **Friction:** Verify opening relevance, actionable next step, scanability and channel length.
8. **Final audit:** use `human-writing-audit` for linguistic artifacts only after substantive defects are fixed.

## Change scope
For a local request, make local changes and report any structural issue separately. For a full rewrite request, preserve the argument and document material decisions. Do not force a complete rewrite because the reviewer dislikes one sentence.

## Outputs
Final editable draft first. For complex reviews, a compact issue table containing original issue, reason and intervention. Do not bury the usable copy beneath editorial theater.

## Quality gates
A paragraph earns space through a distinct claim, evidence or useful action. The copy passes buyer comprehension, fidelity, proof and negative-lexicon review. A purely stylish revision is not success if it weakened substance.
